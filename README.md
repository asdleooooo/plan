# Codex Double-Loop Bootstrap

This repository bootstraps the workflow described in `PLAN.md`:
- Plan loop: requirements/UI -> `plans/<ticket_id>/plan.md`
- Implement loop: `plan.md` + feedback -> code updates + verification + report

## Quick start

```bash
npm run verify
```

## Directory convention

- `docs/requirements/`
- `docs/ui/`
- `plans/<ticket_id>/`
- `scripts/codex/`
- `.github/workflows/`
